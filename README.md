# Egypto 🇪🇬

Egypto is a Flutter mobile application for renting hotel apartments.

## Project Status

🚧 Under Development

## Tech Stack

- Flutter
- Dart
- Bloc / Cubit
- REST API
- Dio

## Features

- Authentication
- Property browsing
- Search & filters
- Booking
- Favorites
- Host management
- Arabic / English
- RTL / LTR
- Dark / Light mode

## Architecture

The project follows a clean and scalable Flutter architecture.
